## 1. 한 줄 방향

GDGoC DGU 는 **장소에 모이는 커뮤니티**입니다 (화요일 세션, 학기 단위 G-Sprint, 기수마다 바뀌는 사람).
대표 요소가 캠퍼스 지도이므로, 사이트 전체를 **대학 안내판 체계**로 짭니다.
홈의 3D 지도는 **표지**로 그대로 두고, 그 아래는 **전시장**처럼 짭니다.

- 색은 장식이 아니라 **'어디'** 를 뜻합니다. 파랑 = 커뮤니티, 빨강 = 프로젝트, 노랑 = 팀원 찾기, 초록 = 지원 안내.
  지도 · 이름표 · 일정 · 범례 어디서든 같은 뜻으로만 씁니다.
- 주황(#FF6309)은 **'지금 기수'** 표시 하나에만 씁니다 (헤더 기수 태그, 광장 깃발, 연혁의 현재 칸).
- 지어낸 숫자 · 사진 · 후기는 쓰지 않습니다. **실제 기록**(gdg.community.dev 행사, GitHub 프로젝트, 4기 일정)이 이 사이트의 재료입니다.

전시장의 세 가지 규칙
1. **주장 제목**: 이야기 섹션은 '장소 이름표(10px 장소색 네모 + 이름) → 48px 제목 → 한두 줄'로 시작합니다. 제목은 실제 숫자나 사실을 담은 한 문장입니다 ('팀으로 만들어 공개한 서비스 23개'). 숫자는 데이터에서 계산합니다.
2. **진짜를 크게, 많이**: 한 화면에 '큰 실물 1–2개 + 작은 실물 여러 개'로 크기 위계를 만듭니다 (실제 화면 큰 타일 + 실제 로고 아이콘 줄).
3. **세 가지 면**: 흰 · 옅은 회색 · 먹색으로 리듬을 만들고, 모든 페이지를 같은 끝(옅은 회색 '{gen}기에서 만나요' → 먹색 꼬리말)으로 닫습니다.

'와'는 장식이 아니라 크기와 실물에서 나와야 합니다.

## 4. 색 · 면 · 모양

- 글자 `--ink-900 #191B1F` / `--ink-700 #474C55` / `--ink-500 #61666F` (흰 5.8:1 · `--field` 위 5.2:1. 이보다 옅은 글자 금지)
- 선 `--line #E4E6E9`, 진한 선 `--line-strong #C9CDD2`, hover · 누름 면 `--subtle #F6F7F8`
- 장소색 `--place-community` `--place-projects` `--place-teams` `--place-recruits` 는 ① 지도 지붕 ② 장소 표식(이름표 10px 네모 · 목록 8px 네모 · 지붕 픽토그램) ③ 일정 · 범례 표식에만. 글자 · 테두리 · 면에는 쓰지 않습니다.
- 기수색 `--gen` (#FF6309), 그 위 글자는 `--ink-900`
- 포커스 링 `--focus`: 밝은 면 파랑 #4285F4, 먹색 면 #8AB4F8 (8.2:1). 면을 따라 저절로 바뀝니다.

**면은 세 가지, 섹션 단위로만**

| 면 | 토큰 | 쓰는 곳 | class |
|---|---|---|---|
| 흰 | `--paper #FFFFFF` | 기본 | `.story.paper` |
| 옅은 회색 | `--field #F2F4F6` (안쪽 선 `--field-line #E3E6EA`) | 페이지 끝 JoinStrip, 히트맵 · 지원 자격 · 네 파트 같은 이야기 섹션 (안에 흰 판) | `.story.field` |
| 먹색 | `--band-bg #191B1F` (글자 `--band-ink` 흰 · `--band-ink-2 #C9CDD3` · `--band-ink-3 #9BA0A8`, 선 `--band-line #33373E`) | 홈 '어떻게 하나요' 띠, /projects G-Sprint, /community 이번 주, 꼬리말 | `.story.dark.on-dark` |

- 한 페이지에 먹색 면 최대 1개(꼬리말 제외), 옅은 회색 면 최대 2개, **같은 면 두 번 연속 금지** (흰 면은 참고 섹션 · 여백으로 이어질 수 있지만, 페이지 아래쪽이 흰 면으로만 길게 이어지면 이야기 섹션 하나를 옅은 회색으로).
- 섹션 사이는 **면과 여백**으로 나눕니다. 괘선은 목록 · 표 · 이름표 안과 참고 섹션 머리에서만.
- `.on-dark` 는 글자 · 선 · 버튼 · 포커스 단계를 먹색 면 값으로 바꿔 끼웁니다 (안에 들어온 공통 조각이 그대로 4.5:1 을 넘게). 먹색 면 안에 다시 놓인 흰 판은 `.on-light` 로 되돌립니다 (Ticket 이 이미 그렇게 함).
- 상자는 눌러서 이동하는 독립 객체(프로젝트, 행사, 일정 표)와 그림에만. 그림자는 떠 있는 것(지도 미리보기 · 바텀시트 · 검색 창 · 겹친 폰 화면)에만 `--shadow-float`.

**모양**: radius `--r-tag` 6(태그) / `--r-control` 12(버튼 · 입력 · 거르기) / `--r-card` 16(글자 카드 · 표 · 판) / `--r-media` 20(그림 타일 · 일정 표). 아이콘 타일은 정사각 기준 24%. 원은 아바타와 구글 원에만.
로고 · 앱 아이콘은 **흰 판 위**에 둡니다 (아이콘 타일은 로고 62%, 카드 표지는 56% × 52%). 회색 면 위에 로고를 놓지 않습니다.

## 5. 간격 · 격자 · 섹션

- 12칸, 최대 폭 1200, 거터 24. 좌우 여백 1280↑ 자동, 768–1279 40, 768↓ 20 (+ safe-area)
- 간격 의미는 세 단계: 묶음 안 8–12 · 묶음 사이 32–48 · 섹션 사이(아래 두 가지).

**섹션은 두 가지**

| | 이야기 섹션 | 참고 섹션 |
|---|---|---|
| 무엇 | 이 동아리가 하는 말 (프로젝트 · 띠 · 지원 자격 · 히트맵 · 끝) | 찾아 읽는 것 (FAQ · 일정 목록 · 지원 과정 · 기록) |
| 머리 | 이름표 → 주장 제목(48, 먹색은 64) → 한 줄 \| 오른쪽 행동 하나 | 1px 괘선 + 제목 28 + 한 줄. 위(기본) 또는 왼쪽 3칸 |
| 내용 | 12칸 전체 | 12칸 전체(위 머리) · 4–12칸(왼쪽 머리) |
| 여백 | 위아래 안쪽 `--story-pad` 136 / 104(≤1023) / 72(≤767), 머리 → 내용 `--head-gap` 56 / 44 / 28 | 섹션 사이 `--gap-section-near` 96 (폰 64) |
| 부품 | `common/StorySection` | `pages/PageParts` 의 `Section` |

- 한 페이지에 이야기 섹션 2–3개. 흰 → 흰 이야기 섹션은 여백 하나만(뒤 섹션의 위 여백 0), 면이 바뀌면 경계가 섹션을 나눕니다.

지금 페이지의 면 순서 (머리 → … → 꼬리말)

| 페이지 | 면 순서 | 이야기 섹션 주장 (숫자는 데이터에서 계산) |
|---|---|---|
| `/` | 지도 → 흰 → **먹색** → 회색(JoinStrip) → 먹색 꼬리말 | '팀으로 만들어 공개한 서비스 {n}개' · '같은 문제를 각자 풀고, 서로의 풀이를 봅니다.' |
| `/projects` | 건물 앞 → 흰(전시실) → **먹색**(4기 G-Sprint) → 회색(JoinStrip) → 꼬리말 | '{n}팀 {m}명이 {데모데이} 데모데이를 향해 만들고 있습니다.' |
| `/community` | 건물 앞 → **먹색**(이번 주) → 흰(다가오는 일정) → 회색(1년 달력) → 흰(기수별 기록) → 회색(JoinStrip) → 꼬리말 | '매주 화요일 18:00에 모입니다' · '세 기수가 연 공개 행사 {n}번' (`heatmap.ts yearRows` 의 지난 행사 합) |
| `/recruits` | 건물 앞 → 회색(지원 자격) → 흰(한 해) → 회색(네 파트) → 흰(자주 묻는 질문) → 꼬리말 | '전공 · 학년과 상관없이 지원할 수 있습니다' · '파트마다 같은 문제를 각자 풀고 비교합니다' |
| `/teams` | 건물 앞 → 회색(JoinStrip 팀원 찾기 변형) → 꼬리말 | '팀원 찾기는 준비하고 있습니다' |

- /community '이번 주' 먹색 면은 넓은 화면(1200↑)에서 머리 5칸 | 큰 표 7칸, 그 아래는 위아래로. 큰 숫자 묶음은 이 표 하나이고, 기록 섹션의 멤버 · 프로젝트 수는 글줄('그룹 멤버 244명 · 공개 프로젝트 23개 · 2026.10 기준')로 낮춥니다.
- 홈 첫 화면(지도) 바로 다음 이야기 섹션은 위 여백을 줄여 지도와 제목 사이 약 96px.

## 6. 움직임

- 120ms(hover) / 200ms(펼침) / 320ms(시트), `cubic-bezier(.2,0,0,1)`. 튕김 없음.
- 연출은 한 번: 첫 방문 때 광장 깃발이 올라감. '동작 줄이기'면 처음부터 올라가 있음.
- 페이지를 옮길 때만 한 번: 머리말은 그대로, 본문만 120ms 사라지고 240ms 나타남(위치 이동 없음). 메뉴 밑줄은 미끄러짐. 홈 지도에서 건물이 보이면 그 건물 쪽으로 1.1배 다가가며 들어감.
- 창은 열림보다 닫힘이 빠르게(140ms). 누름은 0.98배 80ms. 화면 그림(screen · promo · mobile) hover 는 1.03배 480ms, 로고는 커지지 않습니다. **hover 는 마우스가 있는 화면에서만**(`@media (hover: hover)`, 모든 `:hover` 규칙을 이 안에 씁니다).
- 사이트 안 → 는 hover 때 3px 나아가고, 바깥 ↗ 는 오른쪽 위로 1px.
- 상태 표시는 실제 데이터로만 (예: G-Sprint 기간에는 프로젝트 랩 창에 불이 켜짐).
- '동작 줄이기'면 모두 끈다.

## 7. 버튼 · 링크 · 태그

행동 무게는 세 단계입니다.

| 단계 | class | 모양 | 규칙 |
|---|---|---|---|
| 주 버튼 | `.btn-primary` | 높이 52 · radius 12 · 먹색 바탕 흰 600 16px. 먹색 면 위에서는 흰 바탕 | **한 화면에 하나** |
| 두 번째 버튼 | `.btn-secondary` | 높이 52 · radius 12 · `--field` 바탕. 옅은 회색 면 위에서는 흰 바탕 + 1px 선, 먹색 면 위에서는 #2B2E34 | 주 버튼 옆, 또는 섹션 끝 '모두 보기' |
| 사이트 안 이동 | `.link-go` | 600 16px · 밑줄 없음 · 끝에 → · 높이 44 | hover 때 밑줄. 섹션 머리 오른쪽 행동 |

- 작은 크기 `.btn-sm`: 높이 40 · radius 10 (머리말 '지원 안내'). 누르는 자리는 44.
- 버튼 줄 `.btn-row`: 폰(≤767)에서 주 버튼 · 두 번째 버튼이 둘 다 한 줄 가득.
- **밑줄(`.link`)은 문장 · 표 · 각주 안 링크에만.** 목록 · 꼬리말 링크는 밑줄 없이 hover · 지금 페이지만 밑줄.
- **↗ = 사이트 밖**(새 창, 밑줄은 글자에만, 화살표는 밑줄 밖), **→ = 사이트 안**.
- 머리말: 메뉴 15/22 600, 활성은 2px 밑줄(미끄러짐), hover 는 옅은 밑줄이 가운데에서 펴짐. 메뉴에는 이름만('준비 중' 배지 없음). 오른쪽 '지원 안내'는 두 번째 버튼 작은 크기, /recruits 에 있을 때는 먹색 바탕 · 흰 글자로 '지금 여기'. 폰 메뉴도 같은 규칙.
- 분류 태그: 바탕 없이 장소 표식 + ink-700 13px. '준비 중' 태그는 1px 테두리 (꼬리말 · 그 페이지 머리에서만).

## 8. 사진 · 그림

1. 실제 행사 사진 (드라이브 `01_4기/마케팅/행사 사진`) — 사람이 보이는 컷 우선, 4:3 또는 3:4, 필터 없음
2. 없으면 인스타 카드뉴스 표지 (진짜 기록물)
3. 그것도 없으면 데이터로 그린 '글자 표지': 흰 판 + 날짜(Google Sans Flex 600) + 제목(Pretendard 800). 프로젝트 글자 표지(4번)와 같은 모양이고, 4색 원 같은 장식은 붙이지 않습니다
4. 프로젝트는 팀 저장소 README 의 실제 화면 · 로고를 표지로 겁니다. 기기 목업을 지어내지 않고 1px 선 테두리만. 그림이 없으면 이름 · 기간 · 언어 비율 막대로 만든 글자 표지.
5. **실제 화면끼리 겹쳐 놓는 것은 허용**합니다 (약조심 데스크톱 화면 위에 실제 폰 화면). 기기 틀 · 노치 · 그림자 장식 없이 1px 선, 위에 놓인 화면에만 `--shadow-float`.
6. 큰 그림 타일은 16:10 · radius 20, 아이콘 타일은 정사각 · radius 24% · 로고 62%. 작은 아이콘(40px)에서 가로로 긴 글자 로고(가로 : 세로 2 이상)는 64 × 40 판에 판 폭의 84% 로 둡니다 (정사각에 넣으면 회색 선처럼 보임). 구조도는 자세히 보기 창에서만 (작게 줄이면 회색 선 덩어리).

## 9. 지도

- 받침판 없이 땅과 길이 화면 밖으로 이어집니다. 사람은 화면 밖에서 들어옵니다.
- 벽은 중립색, 장소색은 지붕 · 화면 · 차양 · 톱니창에만. 빛은 왼쪽 위 한 방향.
- 이름표는 안내판: 지붕에서 1px 지시선 → 흰 판(radius 4, 15px 600, 왼쪽 8px 장소색 네모). hover/선택 때 ink 바탕으로 반전.
- 광장 깃발은 기수색(주황) + '4'.
- 지도 위에 카드를 얹지 않습니다. 건물을 누르면 그 자리에서 미리보기가 열립니다(폰은 바텀시트).
- 지도는 홈 첫 화면 · 하위 페이지 머리 · 꼬리말 '현재 위치' 세 곳에만. 더 늘리지 않습니다.

## 9-1. 하위 페이지 머리 (건물 앞)

- 프로젝트 · 커뮤니티 · 지원 안내 · 팀원 찾기는 지도의 그 건물 앞에서 시작합니다 (`features/placehero`). 같은 좌표 · 같은 부품으로 그 건물 쪽을 확대하고, 지금 건물만 장소색, 나머지는 회색 지붕. h1 은 `--t-display`.
- 건물 상태는 실제 데이터로만: G-Sprint 기간 프로젝트 건물 창에 불, 커뮤니티 지붕 화면에 다음 일정, 모집이 열리지 않으면 지원 안내 건물 문이 닫힘, 팀원 찾기는 공사 중(비계 + 흰 가림막, 노랑 · 검정 사선 금지).
- 지붕에서 내려온 안내판(진한 머리 + 줄)이 그 페이지의 목차입니다. 줄은 진짜 링크(44px 이상).
- 넓은 화면 머리 높이 560px 이하. 1024 미만에서는 제목 → 장면(220–240px) → 안내판 목록.
- 장면 속 글자(가림막 · 지붕 화면)는 꾸밈이라 13px 하한의 예외입니다. 같은 내용을 반드시 본문 글자로도 씁니다.

## 9-2. 페이지 끝 · 꼬리말

- 모든 페이지 `<main>` 맨 끝은 **JoinStrip**('{gen}기에서 만나요', 옅은 회색 면) → **먹색 꼬리말**. 페이지가 직접 넣습니다.
  - /recruits 는 넣지 않습니다 (페이지 자체가 같은 내용). /teams 는 `variant="teams"` (질문 자리에 '열리면 생길 것' 세 줄).
  - 하위 페이지의 '여기서 갈 수 있는 곳' 건물 그림 칸은 쓰지 않습니다 (꼬리말 둘러보기와 겹침, 부품도 지웠습니다).
- 본문이 이야기 섹션으로 끝나면 꼬리말이 위 여백 없이 바로 붙고, 참고 섹션 · 글로 끝나면 흰 여백 144(폰 88)를 둡니다.
- 꼬리말: 먹색 면, 링크 밑줄은 hover · 지금 페이지만, 포커스 링 #8AB4F8. 둘러보기 아래 '현재 위치' 작은 지도는 옅은 판(#F4F6F8, radius 14) 위에, 지금 페이지 건물만 장소색. '홈' 표식은 흰색.
- 꼬리말 칸: 이름 · 둘러보기 · 연락 · 지금 기수. 바깥 채널(인스타그램 · GitHub · 챕터 페이지)은 모두 '어디'라는 이름으로 '연락' 목록에 둡니다. '{gen}기 소식 받기' 같은 행동 버튼은 꼬리말에 두지 않습니다 (바로 위 JoinStrip, /recruits 는 머리가 맡음 — 같은 버튼이 한 화면에 두 번 나오지 않게).
- 1280 이상은 네 칸(3 · 3 · 3 · 3), 768–1279 는 이름을 맨 위 한 줄로 올리고 아래 세 칸을 4 · 5 · 3 으로 (주소 · 바깥 링크가 꺾이지 않게), 767 이하는 한 칸.

## 10. 콘텐츠 원칙

- 숫자에는 기준을 붙입니다: `멤버 244명 · gdg.community.dev 기준 2026.10`. 주장 제목의 숫자는 한 줄 아래 또는 꼬리말 출처 줄에 기준을 둡니다.
- 숫자는 데이터에서 계산합니다 (공개 프로젝트 수 · 행사 수 · D-day). 손으로 적지 않습니다. 커밋 합계는 쓰지 않습니다.
- 미정인 것은 세 가지를 적습니다: 지금 상태 · 확정 예정 시기 · 먼저 공지할 채널.
- 비어 있는 섹션은 띄우지 않습니다 (후기가 0개면 후기 섹션을 숨김).
- 공개 출처가 있는 사실만 씁니다. 출처는 `src/content/*.json` 의 `source` 에 남깁니다.
- 문장은 ~습니다체. 이름(GDGoC DGU, G-Sprint, 행사 정식 명칭) · 기술 이름만 영어.
