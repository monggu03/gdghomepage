# 디자인 원칙: 캠퍼스 안내판

> 2026-10-16 리디자인 기준 문서. 화면을 새로 만들거나 고칠 때 이 문서부터 읽습니다.
> 근거: 국내 IT 동아리 · GDG 챕터 사이트 21곳 조사, 오픈소스 동아리 사이트 13곳 구조 조사, 'AI가 만든 것 같은 화면' 비평.

## 1. 한 줄 방향

GDGoC DGU 는 **장소에 모이는 커뮤니티**입니다 (화요일 세션, 학기 단위 G-Sprint, 기수마다 바뀌는 사람).
대표 요소가 캠퍼스 지도이므로, 사이트 전체를 **대학 안내판 체계**로 짭니다.

- 색은 장식이 아니라 **'어디'** 를 뜻합니다. 파랑 = 커뮤니티, 빨강 = 프로젝트, 노랑 = 팀원 모집, 초록 = 지원 안내.
  지도 · 메뉴 · 일정 · 범례 어디서든 같은 뜻으로만 씁니다.
- 주황(#FF6309)은 **'지금 기수'** 표시 하나에만 씁니다 (헤더 기수 태그, 광장 깃발, 연혁의 현재 칸).
- 나머지는 흰 종이 위 먹색 글자입니다.
- 지어낸 숫자 · 사진 · 후기는 쓰지 않습니다. **실제 기록**(gdg.community.dev 행사, GitHub 프로젝트, 4기 일정)이 이 사이트의 재료입니다.

## 2. 하지 않는 것 (AI · 템플릿 티)

- 흐린 색 덩어리 배경, 유리 효과(blur), 그라데이션 글자, 구글 4색 줄무늬 띠
- 카드 왼쪽 색 띠, 의미 없는 상태 점, 제목 위 아이콘 타일 · 알약 라벨
- 같은 카드 n장 나란히, 지그재그 배치, 자동으로 흐르는 후기, 숫자 카운트업, 스크롤 페이드업, 튕기는 움직임
- 'GDGoC DGU ○○' 식 반복 제목, '핵심 가치' 같은 채움말, 영어 슬로건, 기준 없는 '200+' 숫자, 빈 섹션 공개
- 파스텔 자리 표시 그림, 스톡 · AI 인물 사진
- 구글 색 글자(특히 노랑), 파랑 링크, 주황을 강조 · hover · '오늘'에 쓰기
- 모든 것을 알약 모양으로, 모든 것에 그림자
- 구글 G 로고 · 동국대 교표 사용, GDG 로고를 글자로 다시 조립하기
- 13px 미만 한글, -0.04em 보다 좁은 자간

## 3. 글자

- 한글 문장은 **Pretendard** 하나로 씁니다. 문장 안의 영문('G-Sprint 중간 발표')도 Pretendard 그대로 둡니다.
- **Google Sans Flex** 는 숫자 덩어리(D-11, 날짜, 연도, 통계)와 영문 워드마크에만 씁니다 (`--font-num`).
- 날짜 표기는 하나로: `10.27 화`. 연도가 다르면 `2027.01.30 토`.
- 전역: `word-break: keep-all`, 제목 `text-wrap: balance`, 본문 최대 폭 38em.

| 역할 | 데스크톱 | 폰 | 굵기 | 자간 |
|---|---|---|---|---|
| 디스플레이 | 56/72 | 32/42 | 800 | -0.025em |
| 섹션 제목 | 40/52 | 26/36 | 700 | -0.02em |
| 소제목 | 28/38 | 21/30 | 700 | -0.015em |
| 항목 제목 | 20/30 | 18/27 | 700 | -0.01em |
| 리드 | 20/34 | 17/28 | 400 | -0.01em |
| 본문 | 17/28 | 16/26 | 400 | -0.005em |
| UI · 버튼 | 15/22 | 15/22 | 600 | 0 |
| 메타 (하한) | 13/20 | 13/20 | 500 | 0 |
| 큰 숫자 | 64/64 | 44/44 | 600 (Google Sans Flex) | -0.02em |

토큰: `--t-display` `--t-h1` `--t-h2` `--t-h3` `--t-lead` `--t-body` `--t-ui` `--t-meta` `--t-num` (styles/tokens.css)

## 4. 색 · 면

- 바탕 `--paper #FFFFFF`, 옅은 면 `--subtle #F6F7F8`, 선 `--line #E4E6E9`, 진한 선 `--line-strong #C9CDD2`
- 글자 `--ink-900 #191B1F` / `--ink-700 #474C55` / `--ink-500 #6E737C` (이보다 옅은 글자 금지, 4.7:1)
- 장소색 `--place-community` `--place-projects` `--place-teams` `--place-recruits` 는 ① 지도 지붕 ② 장소 표식(8px 네모 · 지붕 픽토그램) ③ 일정 · 범례 표식에만
- 기수색 `--gen` (#FF6309), 그 위 글자는 `--ink-900`
- 링크: ink-900 + 1px 밑줄(offset 3px). 포커스 링만 파랑 2px.
- 기본은 **상자 없이** 흰 바탕 + 1px 괘선 + 간격으로 묶습니다.
- 카드는 눌러서 이동하는 독립 객체(프로젝트, 행사)에만: 1px line, radius 12, 그림자 없음, hover 때 테두리 ink-500 + 제목 밑줄.
- 떠 있는 것(지도 미리보기, 바텀시트, 검색 창)만 그림자 `--shadow-float` 를 쓰고 테두리는 없앱니다.
- radius 4(태그) / 8(버튼 · 입력) / 12(카드 · 이미지). 원은 아바타와 구글 원에만.

## 5. 간격 · 격자

- 12칸, 최대 폭 1200, 거터 24. 좌우 여백 1280↑ 자동, 768–1279 40, 768↓ 20 (+ safe-area)
- 섹션 머리(제목 + 한 줄 설명)는 왼쪽 3칸, 내용은 4–12칸.
- 간격 의미는 세 단계뿐: 묶음 안 8–12 · 묶음 사이 32–48 · 섹션 사이 144(폰 88). 이어지는 두 섹션은 96.

## 6. 움직임

- 120ms(hover) / 200ms(펼침) / 320ms(시트), `cubic-bezier(.2,0,0,1)`. 튕김 없음.
- 연출은 한 번: 첫 방문 때 광장 깃발이 올라감. '동작 줄이기'면 처음부터 올라가 있음.
- 상태 표시는 실제 데이터로만 (예: G-Sprint 기간에는 프로젝트 랩 창에 불이 켜짐).

## 7. 버튼 · 링크 · 태그

- 주 버튼: 높이 48(폰 52), radius 8, ink 바탕, 흰 600 16px. **한 화면에 하나.**
- 보조 행동은 밑줄 링크. 화살표는 사이트 밖으로 나가는 ↗ 하나만.
- 분류 태그: 바탕 없이 장소 표식 + ink-700 13px.
- 메뉴 활성: 2px ink 밑줄.

## 8. 사진 · 그림

1. 실제 행사 사진 (드라이브 `01_4기/마케팅/행사 사진`) — 사람이 보이는 컷 우선, 4:3 또는 3:4, 필터 없음
2. 없으면 인스타 카드뉴스 표지 (진짜 기록물)
3. 그것도 없으면 데이터로 그린 '글자 표지': 4색 원 8px + 날짜(Google Sans Flex 600) + 제목(Pretendard 800)

## 9. 지도

- 받침판 없이 땅과 길이 화면 밖으로 이어집니다. 사람은 화면 밖에서 들어옵니다.
- 벽은 중립색, 장소색은 지붕 · 화면 · 차양 · 톱니창에만. 빛은 왼쪽 위 한 방향.
- 이름표는 안내판: 지붕에서 1px 지시선 → 흰 판(radius 4, 15px 600, 왼쪽 8px 장소색 네모). hover/선택 때 ink 바탕으로 반전.
- 광장 깃발은 기수색(주황) + '4'.
- 지도 위에 카드를 얹지 않습니다. 건물을 누르면 그 자리에서 미리보기가 열립니다(폰은 바텀시트).
